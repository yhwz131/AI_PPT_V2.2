# PPTTalK 开发规范文档指南

## 简介

在开始开发前，请根据您的开发需求参考以下规范文档，确保开发过程符合项目标准，提高代码质量和可维护性。

## 规范文档目录

| 文档名称 | 内容描述 | 适用场景 |
|---------|---------|----------|
| **development_process.md** | 新功能开发流程 | 新功能开发、需求分析、项目规划 |
| **CODE_STYLE.md** | 前端代码规范 | 前端开发、代码审查、代码风格统一 |
| **backend_code_guide.md** | 后端代码规范 | 后端开发、API 设计、代码审查 |
| **TESTING_GUIDELINES.md** | 测试规范 | 测试用例设计、测试执行、测试覆盖率 |
| **文档规范.md** | 文档规范 | 技术文档、API 文档、用户文档编写 |
| **INTEGRATION_SPEC.md** | 新功能与现有系统集成规范 | 系统集成、接口设计、兼容性测试 |
| **DEVELOPMENT_GUIDELINES.md** | 完整的开发规范文档 | 综合参考、新成员培训、规范总览 |
| **TRAINING_PLAN.md** | 培训计划 | 团队培训、规范宣导、技能提升 |
| **FEEDBACK_MECHANISM.md** | 反馈机制 | 问题反馈、规范改进、团队协作 |
| **CODE_QUALITY_GUIDELINES.md** | 代码质量检查工具配置 | 代码质量检查、CI/CD 集成 |
| **SPECIFICATION_ENFORCEMENT_MONITORING.md** | 规范执行监督机制 | 规范执行监督、质量保证 |
| **IMPLEMENTATION_PLAN.md** | 实施计划 | 规范实施、项目管理、进度跟踪 |

## 使用指南

1. **开发前**：查看 `development_process.md` 了解开发流程，查看 `DEVELOPMENT_GUIDELINES.md` 了解整体规范
2. **开发中**：参考 `CODE_STYLE.md` 和 `backend_code_guide.md` 确保代码风格一致
3. **测试时**：遵循 `TESTING_GUIDELINES.md` 进行测试
4. **集成时**：参考 `INTEGRATION_SPEC.md` 确保系统集成顺利
5. **文档编写**：按照 `文档规范.md` 编写各类文档
6. **质量保证**：使用 `CODE_QUALITY_GUIDELINES.md` 配置的工具检查代码质量
7. **反馈改进**：通过 `FEEDBACK_MECHANISM.md` 提供反馈，持续改进规范

## 注意事项

- 所有规范文档均位于 `开发规范` 目录下
- 请确保遵循最新版本的规范文档
- 如有疑问或建议，请通过反馈机制提出
- 定期查看规范文档的更新，确保开发实践与最新标准保持一致

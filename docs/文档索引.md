## 前端目录对照（易混）

| 目录 | 角色 |
|------|------|
| **`frontend-new/`** | 当前主用的 Vue 3 + Vite + TypeScript 工程；`npm run build` 输出至 **`frontend-new/dist/`** |
| **`frontend-new/dist/`** | **生产 Nginx 静态根（推荐）**，与 `nginx-myweb.conf` 中 `root` 一致 |
| **`frontend/`** | 可选：构建产物副本（`setup_env.sh` rsync），非必须 |
| **`nginx-myweb.conf`** | 仓库内 Nginx 站点配置备份（HTTPS 5174 等） |
| **`new_frontend/`** | 另一套前端（如 Element Plus），**不是** `setup_env.sh` 默认部署源 |

## 文档文件名前缀「jna」

部分架构/数据流文档以 `jna` 开头，仓库内**无单独全称定义**，可作内部技术文档系列前缀；详见 [各服务配置与常见问题说明.md](各服务配置与常见问题说明.md) 文首说明。

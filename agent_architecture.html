多模态视觉理解

PP-DocLayoutV2 · 精确还原文档原始布局结构，输出标准 Markdown 格式，保留标题层级、段落顺序、列表缩进
🧠
上下文语义理解
DeepSeek · 结合页面背景知识进行语义聚合，生成连贯有逻辑的口播文案，支持跨页面上下文理解
⛓️
LangChain Prompt 工程
提示词链式调用，结构化信息抽取 + 文案生成，内置速率限制器防止 API 调用过载
📊
JSON 结构化输出
JSON Schema + Pydantic · 标准化 JSON 格式输出，包含 page_num、title、content 等标准字段
⚡
GPU 加速与预加载
CUDA 优化 · 推理速度提升 50-60%，模型预加载消除冷启动延迟，支持多 GPU 配置
